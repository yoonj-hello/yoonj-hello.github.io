# [파이썬 기초 4] 반복문 — for와 while로 반복 작업 자동화하기

> 파이썬 입문 가이드 시리즈 4/10
> 정해진 횟수만큼 반복하는 `for`, 조건이 참인 동안 반복하는 `while`, 그리고 `break` / `continue`를 정리합니다.

## 1. `for` 문과 `range()`

```python
for i in range(3):
    print(i)      # 0, 1, 2
```

### `range()` 사용법

| 형태 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `range(끝)` | 0부터 끝-1까지 | `range(3)` | 0, 1, 2 |
| `range(시작, 끝)` | 시작부터 끝-1까지 | `range(1, 11)` | 1 ~ 10 |
| `range(시작, 끝, 증가값)` | 증가값만큼 건너뜀 | `range(10, 20, 2)` | 10, 12, 14, 16, 18 |

> 💡 **끝 값은 포함되지 않습니다.** 1부터 10까지 반복하고 싶다면 `range(1, 11)`처럼 끝 값에 +1을 해줘야 합니다.

```python
for i in range(1, 11):
    print(f"{i}번째 손님 어서오세요")

# 거꾸로 세기: 증가값을 음수로
for i in range(10, 0, -1):    # 10, 9, ... 1
    print(i)

for i in range(10, 0, -2):    # 10, 8, 6, 4, 2
    print(i)
```

변수 `i`를 사용하지 않을 때는 관례적으로 `_`를 씁니다.

```python
for _ in range(3):
    print("hello")
```

### 리스트를 직접 순회하기

```python
for color in ["빨강", "노랑", "파랑"]:
    print(f"오늘의 컬러는 {color}입니다.")

a = ["빨강", "노랑", "파랑"]
for color in a:
    print(color)
```

## 2. 누적 합계 구하기

반복문의 대표적인 활용법입니다. **누적할 변수를 0으로 초기화** → **반복하며 더하기** 순서입니다.

```python
# 1부터 10까지 합
hap = 0
for i in range(1, 11):
    hap = hap + i      # hap += i
print(hap)             # 55
```

```python
# 500과 1000 사이의 홀수의 합
hap = 0
for i in range(501, 1001, 2):
    hap += i
print(f"500과 1000사이에 있는 홀수를 모두 더한 값은 {hap}입니다.")
```

```python
# 1부터 100까지 짝수 출력
for i in range(2, 101, 2):
    print(i)
```

## 3. 중첩 `for` 문

반복문 안에 반복문을 넣을 수 있습니다. 바깥 반복이 1번 돌 때 안쪽 반복은 **처음부터 끝까지** 돕니다.

```python
for i in range(3):         # i = 0, 1, 2
    for j in range(5):     # j = 0, 1, 2, 3, 4
        print(i, j)
```

### 구구단

```python
for i in range(2, 10):
    print(f"--아래는 {i}단입니다.--")
    for j in range(1, 10):
        print(f"{i} x {j} = {i * j}")
```

## 4. `while` 문

조건이 `True`인 **동안** 반복합니다. 반복 횟수가 정해져 있지 않을 때 유용합니다.

```python
i = 0
while i < 3:
    print("수두 조심")
    i = i + 1      # 조건에 영향을 주는 값을 바꿔주지 않으면 무한 반복!
```

### 무한 반복 + `break`

`while True:`로 무한 반복을 만들고, 조건이 맞으면 `break`로 탈출하는 패턴을 많이 씁니다.

```python
while True:
    pw = input("암호를 입력하시오\n")
    if pw == "pythonisfun":
        break
print("로그인 성공")
```

### 입력이 0이 될 때까지 계산하는 프로그램

```python
while True:
    num1 = int(input("1번째 숫자 (0 입력 시 종료): "))
    if num1 == 0:
        break
    num2 = int(input("2번째 숫자: "))
    op = input("연산 기호 (+ - x /): ")

    if op == "+":
        print(f"덧셈: {num1 + num2}")
    elif op == "-":
        print(f"뺄셈: {num1 - num2}")
    elif op == "x":
        print(f"곱셈: {num1 * num2}")
    elif op == "/":
        print(f"나눗셈: {num1 / num2}")
print("정지했습니다.")
```

## 5. `break` 와 `continue`

| 키워드 | 동작 |
|---|---|
| `break` | 반복문을 **완전히 종료** |
| `continue` | 이번 회차만 건너뛰고 **다음 회차로** |

```python
for i in range(1, 11):
    if i % 2 == 0:
        continue      # 짝수는 건너뜀
    if i > 7:
        break         # 7 넘으면 종료
    print(i)          # 1, 3, 5, 7
```

## 6. `for` vs `while` 선택 기준

- **횟수/범위가 정해져 있다** → `for`
- **조건이 만족되는 동안 / 언제 끝날지 모른다** → `while`

---

## ✅ 핵심 정리

- `range(시작, 끝, 증가값)`에서 **끝 값은 포함되지 않습니다.**
- 합계/개수 같은 누적 계산은 변수를 먼저 초기화하고 반복문 안에서 갱신합니다.
- `while`은 조건을 바꾸는 코드가 없으면 **무한 루프**가 됩니다. (멈추려면 터미널에서 `Ctrl + C`)
- `break`는 탈출, `continue`는 건너뛰기입니다.
