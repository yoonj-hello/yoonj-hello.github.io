# [파이썬 기초 2] 연산자 — 계산하고, 비교하고, 판단하기

## 1. 산술 연산자

```python
a = 5
b = 3
print(f"{a}+{b}={a+b}")     # 5+3=8
print(f"{a}-{b}={a-b}")     # 5-3=2
print(f"{a}*{b}={a*b}")     # 5*3=15
print(f"{a}**{b}={a**b}")   # 5**3=125   (거듭제곱)
print(f"{a}/{b}={a/b}")     # 5/3=1.6666666666666667  (나눗셈, 결과는 항상 float)
print(f"{a}//{b}={a//b}")   # 5//3=1     (몫)
print(f"{a}%{b}={a%b}")     # 5%3=2      (나머지)
```

| 연산자 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `+` | 덧셈 | `5 + 3` | `8` |
| `-` | 뺄셈 | `5 - 3` | `2` |
| `*` | 곱셈 | `5 * 3` | `15` |
| `/` | 나눗셈 | `5 / 3` | `1.666...` |
| `//` | 몫 | `5 // 3` | `1` |
| `%` | 나머지 | `5 % 3` | `2` |
| `**` | 거듭제곱 | `5 ** 3` | `125` |

> 💡 `%`(나머지)는 **홀짝 판별**(`n % 2`), **배수 판별**, **자릿수 분리** 등에 매우 자주 쓰입니다.

### 문자열에도 `+`, `*` 사용 가능

```python
print("100" + "100")   # 100100  (이어붙이기)
print("가나" * 3)        # 가나가나가나
```

숫자와 문자열을 섞어서 `+` 하면 오류가 납니다. 형변환을 해주세요.

```python
print("나이: " + str(20))   # OK
# print("나이: " + 20)       # TypeError
```

## 2. 복합 대입 연산자

`a = a + 3`을 `a += 3`으로 줄여 쓸 수 있습니다.

```python
a = 100
a += 3     # 103   (a = a + 3)
a -= 3     # 100
a *= 3     # 300
a /= 3     # 100.0 ← / 는 float가 됨에 주의
a //= 3    # 33.0
a **= 3    # 35937.0
```

## 3. 비교(관계) 연산자

결과는 항상 `True` 또는 `False`입니다.

```python
a, b = 100, 200
print(a == b)   # False  (같다)
print(a != b)   # True   (다르다)
print(a >= b)   # False
print(a <= b)   # True
print(a > b)    # False
print(a < b)    # True
```

> ⚠️ 대입은 `=`, 비교는 `==` 입니다. 가장 흔한 초보자 실수 중 하나입니다.

## 4. 논리 연산자

| 연산자 | 의미 |
|---|---|
| `and` | 둘 다 참이어야 참 |
| `or` | 하나라도 참이면 참 |
| `not` | 참/거짓을 뒤집음 |

```python
a = 150
print((a > 100) and (a < 200))   # True
a = 300
print((a > 100) and (a < 200))   # False
print((a > 100) or (a < 200))    # True
print(not (a < 100))             # True
```

파이썬은 범위 비교를 수학처럼 쓸 수도 있습니다.

```python
print(100 < a < 200)   # (a > 100) and (a < 200) 와 같음
```

## 5. 연산자 우선순위 (높은 순)

1. `**`
2. `*`, `/`, `//`, `%`
3. `+`, `-`
4. 비교 연산자 (`<`, `>`, `==` …)
5. `not` → `and` → `or`

헷갈릴 때는 **괄호 `()`** 를 사용하세요. 가독성도 좋아집니다.

## 6. 비트 연산자 (참고)

`&`(AND), `|`(OR), `^`(XOR), `~`(NOT), `<<`, `>>` 등이 있으며 비트 단위 계산에 쓰입니다. 입문 단계에서는 이름만 알아두셔도 충분합니다.

## 🛠 활용 예제

### ① 두 수의 합

```python
num1 = float(input("첫번째 수를 입력해주세요. \n"))
num2 = float(input("두번째 수를 입력해주세요. \n"))
print(f"입력된 두 수의 합은 {num1 + num2}입니다.")
```

### ② 단위 변환 (파운드 ↔ 킬로그램)

```python
lb = float(input("파운드(lb)를 입력하세요.\n"))
print(f"{lb}(lb)은 {lb * 0.453592}(kg)입니다.")

kg = float(input("킬로그램(kg)를 입력하세요.\n"))
print(f"{kg}(kg)은 {kg * 2.204623}(lb)입니다.")
```

### ③ 거스름돈 계산 (`//` 와 `%` 활용)

```python
inmoney = int(input("투입할 돈의 액수: "))
product = int(input("물건의 액수: "))

if product > inmoney:
    print("돈이 부족합니다!")
else:
    exmoney = inmoney - product          # 거스름돈
    fivecoin = exmoney // 500            # 500원 동전 개수
    onecoin = (exmoney % 500) // 100     # 남은 금액의 100원 동전 개수
    print("거스름돈:", exmoney)
    print("500원 동전의 개수:", fivecoin)
    print("100원 동전의 개수:", onecoin)
```

### ④ 카페 매출 계산

```python
ame = int(input("아메리카노 판매 개수:"))
cafe = int(input("카페라떼 판매 개수:"))
cafu = int(input("카푸치노 판매 개수:"))
total = ame * 2000 + cafe * 3000 + cafu * 3500
print(f"총 매출은 {total}원입니다.")
```

## ✅ 핵심 정리

- `/`는 항상 실수, `//`는 몫, `%`는 나머지.
- 비교 연산의 결과는 `bool`이며, `and` / `or` / `not`으로 조합합니다.
- `==`(비교)와 `=`(대입)을 혼동하지 마세요.
- 복합 대입(`+=`, `*=` …)으로 코드를 간결하게 쓸 수 있습니다.
