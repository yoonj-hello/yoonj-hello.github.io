## 1. 객체지향이란?

프로그램을 **"데이터(속성)" + "기능(메서드)"을 하나로 묶은 객체**들의 상호작용으로 바라보는 방식입니다.

| 용어 | 설명 | 예시 |
|---|---|---|
| **클래스(class)** | 객체를 만들기 위한 **설계도** | `Car` |
| **객체(object) / 인스턴스** | 설계도로 만든 **실제 물건** | `mycar = Car()` |
| **속성(attribute) / 필드** | 객체가 가진 **데이터** | 색상, 속도 |
| **메서드(method)** | 객체가 할 수 있는 **기능** | `upSpeed()` |

> 자동차 설계도(클래스) 하나로 빨간 차, 검은 차, 흰 차(객체)를 여러 대 만들 수 있는 것과 같습니다.

## 2. 클래스와 객체 만들기

```python
class Car:                       # 클래스 이름은 첫 글자를 대문자로 (관례)
    color = ""
    speed = 0

    def upSpeed(self, value):    # 메서드의 첫 번째 매개변수는 항상 self
        self.speed += value
        if self.speed > 150:     # 최대 속도 150으로 제한
            self.speed = 150

    def downSpeed(self, value):
        self.speed -= value

mycar = Car()                    # 객체(인스턴스) 생성
mycar.color = "빨강"
mycar.speed = 0

mycar.upSpeed(60)
print("색상:", mycar.color)       # 빨강
print("속도:", mycar.speed)       # 60
mycar.downSpeed(40)
print("속도:", mycar.speed)       # 20
mycar.upSpeed(200)
print("속도:", mycar.speed)       # 150 (제한 적용)
```

### `self`란?

**"지금 이 메서드를 호출한 바로 그 객체 자신"** 을 뜻합니다. `mycar.upSpeed(60)`을 호출하면 파이썬이 `self`에 `mycar`를 자동으로 넣어줍니다. 그래서 호출할 때는 `self`를 직접 적지 않고, **정의할 때만** 맨 앞에 적습니다.

## 3. 생성자 `__init__`

객체를 만들 때 **자동으로 실행되는 초기화 메서드**입니다. 객체를 만드는 동시에 속성 값을 넣을 수 있어 편리합니다.

```python
class Car1:
    def __init__(self, speed, color, model):
        self.speed = speed       # self.속성 = 값  → 객체마다 따로 저장되는 값
        self.color = color
        self.model = model

    def drive(self):
        self.speed = 60

mycar1 = Car1(0, "blue", "e-class")   # 생성자 호출
print(mycar1.color)    # blue
mycar1.drive()
print(mycar1.speed)    # 60

momcar = Car1(0, "white", "bmw")      # 서로 독립적인 객체
dadcar = Car1(0, "black", "sonata")
print(dadcar.color)    # black
```

### 기본값 매개변수와 함께

```python
class Person:
    def __init__(self, name="", age=0):
        self.name = name
        self.age = age

a = Person("홍길동", 20)
b = Person()               # 기본값 사용
print(a.name, a.age)       # 홍길동 20
```

### `__str__` — `print(객체)` 할 때의 출력 형태 지정

```python
class Car1:
    def __init__(self, speed, color, model):
        self.speed = speed
        self.color = color
        self.model = model

    def __str__(self):
        return f"속도 {self.speed} / 색상 {self.color} / 모델 {self.model}"

print(Car1(0, "blue", "e-class"))   # 속도 0 / 색상 blue / 모델 e-class
```

`__str__`이 없으면 `<__main__.Car1 object at 0x...>` 같은 알아보기 힘든 출력이 나옵니다.

> ⚠️ **클래스 변수 vs 인스턴스 변수**
> 위 2번 예제처럼 `class Car:` 바로 아래에 `color = ""`를 쓰면 **클래스 변수**(모든 객체가 공유하는 기본값)입니다. 실무에서는 `__init__` 안에서 `self.color = ...`로 만드는 **인스턴스 변수**를 쓰는 것이 일반적이고 안전합니다. 특히 리스트 같은 변경 가능한 값을 클래스 변수에 두면 모든 객체가 하나를 공유해 버리니 주의하세요.

## 4. 상속 (Inheritance)

기존 클래스의 **속성과 메서드를 그대로 물려받아** 재사용하고, 필요한 부분만 추가/수정할 수 있습니다.

```python
class 자식클래스(부모클래스):
    ...
```

### 기본 예제 — 동물

```python
class Animal:
    def sound(self):
        print("동물의 소리")

class Dog(Animal):
    def sound(self):          # 부모의 메서드를 다시 정의 → 오버라이딩
        print("멍멍")

class Cat(Animal):
    def sound(self):
        print("야옹")

mimi = Dog()
mimi.sound()    # 멍멍
navi = Cat()
navi.sound()    # 야옹
```

같은 `sound()` 호출이지만 **객체에 따라 다르게 동작**하는 것을 **다형성**이라고 합니다.

### `super()` — 부모 생성자 호출

```python
class Car2:
    def __init__(self, color="", speed=0):
        self.color = color
        self.speed = speed

    def upSpeed(self, value):
        self.speed += value

    def downSpeed(self, value):
        self.speed -= value

class Passenger(Car2):                       # 승용차
    def __init__(self, color="", speed=0, seat=4):
        super().__init__(color, speed)       # 부모(Car2)의 생성자로 color, speed 초기화
        self.seat = seat                     # 승용차만의 속성 추가

    def getSeat(self):
        return self.seat

class Truck(Car2):                           # 트럭
    def __init__(self, color="", speed=0, capacity=1000):
        super().__init__(color, speed)
        self.capacity = capacity

    def getCapacity(self):
        return self.capacity

    def upSpeed(self, value):                # 메서드 오버라이딩: 트럭은 최고속도 150 제한
        self.speed += value
        if self.speed > 150:
            self.speed = 150
```

실행해 보면:

```python
mycar = Passenger("빨강", 100, 5)
print(mycar.color)       # 빨강   (Car2에서 상속)
print(mycar.speed)       # 100    (Car2에서 상속)
print(mycar.getSeat())   # 5      (Passenger 고유)

truck = Truck("파랑", 0, 2000)
truck.upSpeed(200)
print(truck.speed)         # 150   (오버라이딩된 메서드 적용)
truck.downSpeed(100)       # Car2의 메서드를 그대로 사용
print(truck.speed)         # 50
print(truck.getCapacity()) # 2000
```

### 상속의 장점

- **코드 재사용**: 공통 기능(`color`, `speed`, `upSpeed` …)을 부모에 한 번만 작성
- **유지보수 용이**: 공통 부분을 고치면 모든 자식에 반영
- **확장성**: 자식 클래스에서 새로운 기능을 추가하거나 기존 기능을 변경

## 🛠 활용 예제: 자판기 음료를 클래스로 바꿔 보기

8편에서 `[이름, 가격, 재고]` 리스트로 관리했던 음료를 클래스로 표현하면 훨씬 읽기 쉬워집니다.

```python
class Drink:
    def __init__(self, name, price, amount):
        self.name = name
        self.price = price
        self.amount = amount

    def is_soldout(self):
        return self.amount == 0

    def sell(self):
        if self.is_soldout():
            return False
        self.amount -= 1
        return True

    def __str__(self):
        return f"{self.name} ({self.price}원, 재고 {self.amount}개)"

drinks = [Drink("물", 800, 2), Drink("핫식스", 2000, 5), Drink("옥수수수염차", 1600, 0)]

for d in drinks:
    print(d, "→ 품절" if d.is_soldout() else "→ 판매중")

drinks[0].sell()
print(drinks[0])      # 물 (800원, 재고 1개)
```

`drink[0][2]` 같은 번호 대신 `drink.amount`처럼 **이름으로 접근**할 수 있어 실수가 줄어듭니다.

## ✅ 핵심 정리

- **클래스**는 설계도, **객체**는 설계도로 만든 실체입니다.
- 메서드의 첫 매개변수는 항상 `self`이고, 속성은 `self.이름`으로 접근합니다.
- `__init__`은 객체 생성 시 자동 실행되는 생성자, `__str__`은 출력 형태를 정합니다.
- `class 자식(부모):`로 상속하고, `super().__init__()`으로 부모 생성자를 호출합니다.
- 부모의 메서드를 자식에서 다시 정의하는 것이 **오버라이딩**입니다.
