# 기본 입출력
```python
print("Hello World")
```
괄호 안 문자열을 출력한다.

```python
a = 10
print(a)
b = "Hello"
print(b)
```
변수를 활용한 출력도 가능하다.

```python
print("123\n456\n789") #\n
print("123\t456\t789") #\t 
print("123\"456\"789") #\"
print("123\\456\\789") #\\
```
문자열 출력 관련한 여러 서식문자가 있다.
\n은 줄 바꿈, \t는 4칸 띄우기.
\"는 "를 문자로 인식되게 한다.
\\는 \를 문자로 인식되게 한다.

```python
name = input("이름을 입력하세요")
```
input 함수를 활용해 괄호 안 문자열을 출력 후 입력을 받는다.
받은 입력은 선언한 변수(예시에선 name)에 저장된다.

# 문자열 포맷팅(String Formatting)
```python
name = input("이름을 입력하세요\n")
print(f"'{name}'씨 안녕하세요")
```
가장 많이 쓰는 f-string 기법.
print 함수의 괄호 안 문자열의 앞에 f를 붙이고, 변수나 식을 {변수}와 같이 작성한다.

```python
print("%d" % (100)) 
print("%f + %d = %d" % (13.5, 14.5, 28))
print("%c" % "b")
print("%s" % "bb")
```
C언어와 비슷하게 서식 문자를 활용한 방법도 있다.
%d는 정수, %f는 실수, %c는 문자, %s는 문자열에 대응된다.

```python
print("i like {} {} {} ".format(123,456,789))
```
format 메소드를 활용하기도 한다. {}로 위치를 지정하고, format 메소드에서 값을 지정한다.
