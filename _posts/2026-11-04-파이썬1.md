# [파이썬 기초 1] 변수와 데이터 — 값을 담고, 출력하고, 입력받기

> 파이썬 입문 가이드 시리즈 1/10
> 이 글에서는 `print()`로 출력하기, 변수와 자료형, 출력 서식, 입력받기까지 파이썬의 가장 기본이 되는 내용을 정리합니다.

---

## 1. 출력하기: `print()`

```python
print("Hello world!")
print(123)
print("a", "b", "c")      # 여러 값을 쉼표로 구분하면 공백으로 이어서 출력
print("A", end="")        # end="" 이면 줄바꿈 없이 출력
print("학점입니다")        # → A학점입니다
```

`print()`는 기본적으로 출력 후 줄바꿈을 합니다. 줄바꿈을 없애고 싶으면 `end=""`를 사용합니다.

## 2. 변수

변수는 **값을 담아두는 이름표**입니다. 선언 없이 `=`로 값을 대입하면 바로 만들어집니다.

```python
a = 1
a = 10          # 같은 이름에 다시 대입하면 값이 바뀜
b = 20
print(a, "+", b, "=", a + b)   # 10 + 20 = 30
```

### 한 번에 여러 변수 다루기

```python
c, d = 3, 4          # 동시에 대입
a = b = c = d = 100  # 같은 값을 모두에게 대입
```

### 변수 이름 규칙

- 대소문자를 구분합니다. (`age`와 `Age`는 다른 변수)
- 숫자로 시작할 수 없습니다. (`1st` ❌ / `first` ✅)
- 예약어(`if`, `for`, `while` 등)는 사용할 수 없습니다.
- 특수문자는 `_`(언더바)만 사용할 수 있습니다.

## 3. 기본 자료형

| 자료형 | 이름 | 예시 |
|---|---|---|
| `int` | 정수 | `345`, `-7` |
| `float` | 실수 | `3.14`, `0.0` |
| `str` | 문자열 | `"python"`, `'123'` |
| `bool` | 불(참/거짓) | `True`, `False` |

`type()`으로 자료형을 확인할 수 있습니다.

```python
a = "123"
print(type(a))      # <class 'str'>
print(type(345))    # <class 'int'>
print(type(3.14))   # <class 'float'>
print(type(100 > 300))  # <class 'bool'>
```

> 💡 `"123"`처럼 따옴표 안에 있으면 숫자처럼 보여도 **문자열**입니다.

### 진법 표현

```python
b = 0xff      # 16진수 → 255
c = 0o77      # 8진수  → 63
d = 0b1111    # 2진수  → 15
print(b, c, d)   # 출력할 때는 자동으로 10진수로 변환됨

print(bin(42))   # 0b101010  (10진수 → 2진수)
print(hex(42))   # 0x2a      (10진수 → 16진수)
print(oct(42))   # 0o52      (10진수 → 8진수)
print(int('0b101010', 2))   # 42 (문자열 → 10진수)
```

## 4. 문자열 다루기

```python
b = "한국공학대 '1학년'"   # 바깥이 큰따옴표면 안쪽 작은따옴표는 그냥 글자
s = """오늘의 뉴스
중동쇼크
기름값 언제 내리나..."""     # 큰따옴표 3개: 여러 줄 문자열
print(s)
```

### 이스케이프 문자

| 표기 | 의미 |
|---|---|
| `\n` | 줄바꿈 |
| `\t` | 탭 |
| `\"` | 큰따옴표 문자 |
| `\\` | 역슬래시 문자 |

```python
print("123\n456\n789")
print("123\t456\t789")
print("123\"456\"789")
print("123\\456\\789")
```

## 5. 출력 서식 3가지

### ① `%` 서식 지정자

```python
print("%d" % 100)                 # 정수
print("%f" % 123.45)              # 실수 (소수점 6자리)
print("%.1f" % 123.54)            # 소수점 첫째 자리까지 → 123.5
print("%s" % "python")            # 문자열
print("%c" % "b")                 # 문자 1개
print("%5d" % 123)                # '  123'  (총 5칸, 오른쪽 정렬)
print("%05d" % 123)               # '00123'  (빈칸을 0으로 채움)
print("%7.1f" % 123.456)          # '  123.5' (총 7칸, 소수점 1자리, 반올림)
print("%10s" % "python")          # 총 10칸 오른쪽 정렬
print("%d + %d = %d" % (3, 4, 7)) # 여러 개는 괄호(튜플)로 묶기
```

### ② `.format()`

```python
print("i like {} {} {}".format(123, 456, 789))
print("{0:d} {1:5d} {2:05d}".format(123, 456, 789))
print("{2:05d} {1:05d} {0:05d}".format(123, 456, 789))  # 번호로 순서 지정
```

### ③ f-string (가장 추천 ⭐)

문자열 앞에 `f`를 붙이고 `{}` 안에 변수나 식을 바로 넣습니다.

```python
year, month, today = 2026, 3, 20
print(f"오늘은 {year}년 {month}월 {today}일 입니다.")
print(f"합계: {10 + 20}")
print(f"{3.14159:.2f}")   # 3.14 (서식도 지정 가능)
```

## 6. 입력받기: `input()`

```python
name = input("이름을 입력하세요\n")
print(f"'{name}'씨 안녕하세요")
print(name + "씨 안녕하세요")      # 문자열끼리는 + 로 이어붙임

age = input("나이를 입력하세요\n")
print(f"안녕하세요 {name}씨! 올해 나이가 {age}세이시군요")
```

> ⚠️ **`input()`은 항상 문자열(str)을 돌려줍니다.** 숫자로 계산하려면 반드시 형변환이 필요합니다.

## 7. 형변환

```python
int("123")      # 123    문자열 → 정수
float("3.14")   # 3.14   문자열 → 실수
str(100)        # "100"  숫자 → 문자열

num = int(input("숫자 입력: "))   # 입력과 동시에 정수로 변환
```

```python
c = "100"
print(c + "100")      # 100100 (문자열 이어붙이기)
print(int(c) + 100)   # 200    (숫자 덧셈)
```

## ✅ 핵심 정리

- 변수는 `=`로 값을 대입해 만들며, 자료형은 값에 따라 자동으로 정해집니다.
- 기본 자료형은 `int`, `float`, `str`, `bool`이고 `type()`으로 확인합니다.
- 출력 서식은 **f-string**이 가장 간편합니다.
- `input()`의 결과는 항상 문자열이므로 계산에는 `int()`, `float()`로 변환합니다.
