> 파이썬 입문 가이드 시리즈 6/10
> 리스트 `[]`, 튜플 `()`, 딕셔너리 `{}` — 비슷해 보이지만 용도가 다른 자료구조들을 비교하며 정리합니다.

---

## 0. 한눈에 비교

| 자료구조 | 표기 | 순서 | 수정 | 중복 | 특징 |
|---|---|---|---|---|---|
| 리스트 `list` | `[1, 2, 3]` | O | O | 허용 | 가장 범용적 |
| 튜플 `tuple` | `(1, 2, 3)` | O | **X** | 허용 | 변경 불가(읽기 전용) |
| 셋 `set` | `{1, 2, 3}` | X | O | **불가** | 집합 연산에 강함 |
| 딕셔너리 `dict` | `{"a": 1}` | O(3.7+) | O | 키 중복 불가 | **키 → 값** 쌍 |

## 1. 튜플 (Tuple)

**한 번 만들면 값을 바꿀 수 없는 리스트**라고 생각하면 됩니다.

```python
t = (10, 20, 30)
print(t[0])        # 10
print(t[-1])       # 30
print(t[1:])       # (20, 30)
print(len(t))      # 3
print(20 in t)     # True

# t[0] = 99        # TypeError! 수정 불가
```

### 원소가 1개인 튜플은 쉼표가 필수

```python
a = (5,)    # 튜플
b = (5)     # 그냥 정수 5
```

### 언패킹

```python
point = (3, 4)
x, y = point
print(x, y)      # 3 4

# 변수 값 교환도 사실 튜플
a, b = 1, 2
a, b = b, a
print(a, b)      # 2 1
```

### 언제 쓸까?

- 좌표 `(x, y)`, 색상 `(255, 0, 0)`처럼 **바뀌면 안 되는 묶음**
- 함수가 값을 **여러 개 반환**할 때 (실제로는 튜플로 반환됨)

```python
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([3, 1, 4, 1, 5])
print(lo, hi)    # 1 5
```

리스트 ↔ 튜플 변환: `list(t)`, `tuple(lst)`

## 2. 셋 (Set)

**중복이 없고 순서가 없는** 자료구조입니다. 수학의 집합과 같습니다.

```python
s = {1, 2, 3, 3, 2}
print(s)           # {1, 2, 3}  중복 자동 제거

empty = set()      # 빈 셋은 {} 가 아니라 set() !  ({}는 빈 딕셔너리)
```

### 주요 메서드

```python
s = {1, 2, 3}
s.add(4)           # 추가
s.add(2)           # 이미 있으면 무시
s.remove(1)        # 삭제 (없으면 KeyError)
s.discard(99)      # 삭제 (없어도 에러 없음)
print(3 in s)      # True — 포함 검사가 리스트보다 빠름
```

### 집합 연산

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(a | b)    # {1, 2, 3, 4, 5, 6}  합집합
print(a & b)    # {3, 4}              교집합
print(a - b)    # {1, 2}              차집합
print(a ^ b)    # {1, 2, 5, 6}        대칭차집합
```

### 활용: 리스트 중복 제거

```python
nums = [1, 2, 2, 3, 3, 3]
unique = list(set(nums))
print(unique)     # [1, 2, 3]  (순서는 보장되지 않음)
```

### 활용: 로또 번호가 겹치지 않는 이유

`random.sample()`이 중복 없이 뽑는 것과 같은 개념입니다.

## 3. 딕셔너리 (Dictionary)

**키(key)와 값(value)을 한 쌍으로** 저장합니다. 사전에서 단어(키)로 뜻(값)을 찾는 것과 같습니다.

```python
student = {"name": "홍길동", "age": 20, "major": "컴퓨터공학"}
print(student["name"])     # 홍길동
```

### 값 조회 / 추가 / 수정 / 삭제

```python
student["age"] = 21             # 수정
student["grade"] = 1            # 없는 키면 새로 추가
del student["major"]            # 삭제

print(student.get("name"))          # 홍길동
print(student.get("phone"))         # None  (없는 키여도 에러 X)
print(student.get("phone", "없음"))  # 없음  (기본값 지정)
# print(student["phone"])           # KeyError!

print("name" in student)       # True  (키 존재 여부)
print(len(student))
```

### 순회하기

```python
for k in student:                   # 키만
    print(k)

for v in student.values():          # 값만
    print(v)

for k, v in student.items():        # 키와 값 모두 (가장 많이 사용)
    print(f"{k}: {v}")
```

### 주요 메서드

| 메서드 | 설명 |
|---|---|
| `keys()` | 모든 키 |
| `values()` | 모든 값 |
| `items()` | (키, 값) 쌍 |
| `get(k, 기본값)` | 안전한 조회 |
| `pop(k)` | 키 삭제 후 값 반환 |
| `update(다른딕셔너리)` | 병합 |
| `clear()` | 전체 삭제 |

### 리스트 안의 딕셔너리 — 실전에서 가장 많이 쓰는 형태

자판기 상품 데이터를 중첩 리스트가 아니라 딕셔너리로 관리하면 훨씬 읽기 쉽습니다.

```python
# 리스트 방식: drink[0][1] 이 뭔지 알기 어려움
drink = [["물", 800, 2], ["핫식스", 2000, 5]]

# 딕셔너리 방식: 의미가 명확
drink = [
    {"name": "물",    "price": 800,  "stock": 2},
    {"name": "핫식스", "price": 2000, "stock": 5},
]
for d in drink:
    print(f"{d['name']}: {d['price']}원 (재고 {d['stock']}개)")
```

### 활용: 글자 개수 세기

```python
text = "banana"
count = {}
for ch in text:
    count[ch] = count.get(ch, 0) + 1
print(count)    # {'b': 1, 'a': 3, 'n': 2}
```

## ✅ 핵심 정리

- **튜플**: 수정 불가. 바뀌면 안 되는 묶음, 여러 값 반환에 사용.
- **셋**: 중복 제거, 포함 검사, 집합 연산(`|`, `&`, `-`). 빈 셋은 `set()`.
- **딕셔너리**: 키로 값을 찾는 구조. `get()`으로 안전하게 조회하고 `items()`로 순회.
- 리스트가 "순서 있는 목록", 딕셔너리가 "이름표 붙은 데이터"라고 기억하면 선택이 쉽습니다.
